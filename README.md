# 🤖 YouTube Music Automation (Python)

Automação desenvolvida em Python utilizando a biblioteca `pyautogui` para abrir o navegador, acessar o YouTube, pesquisar uma música e iniciar a reprodução automaticamente.

## 🚀 Funcionalidades

* Abre o navegador automaticamente
* Acessa o YouTube
* Pesquisa uma música específica
* Reproduz o vídeo automaticamente
* Ativa modo tela cheia

## 🛠️ Tecnologias utilizadas

* Python 3
* PyAutoGUI
* Time (controle de execução)

## ▶️ Como executar

1. Instale as dependências:

```bash
pip install pyautogui
```

2. Execute o script:

```bash
python main.py
```

## ⚠️ Observações importantes

* O script interage diretamente com o mouse e teclado
* Não utilize o computador durante a execução
* Pode variar dependendo da resolução da tela e velocidade da internet
* Recomenda-se ajustar os tempos (`time.sleep`) conforme necessário

## 📌 Exemplo de execução

```text
🎵 Iniciando automação...
📺 YouTube aberto
🔍 Buscando música...
▶️ Reproduzindo vídeo...
✅ Finalizado!
```

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar automação de tarefas com Python, simulando interações humanas com o sistema operacional.
